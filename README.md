# ContactManagement

A small local contact manager for storing and organizing contacts. 

## Features
- Add, view, edit, and delete contacts


## Quickstart
1. Clone the repo
   ```bash
   git clone https://github.com/vikask011/contactmanagement.git
   cd contactmanagement
   ```
2. If the project is a static UI: open `frontend/index.html` in your browser.
3. If it's a Node/Python app: install dependencies and run the local app
   - Node example:
     ```bash
     npm install
     npm start
     ```
   - Python example:
     ```bash
     python main.py
     ```

(There is no network API — the app stores data locally in a file or local database.)
